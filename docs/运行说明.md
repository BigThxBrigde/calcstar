# CalcStar 口算练习 · 打包版运行说明

## 一、软件简介

CalcStar 是一款面向小学生的四则运算口算练习桌面应用，基于 Python + PyQt5（内嵌 WebEngine 界面）构建。支持 7 类运算、可自定义数值范围 / 题量 / 限时，自动判分、错题订正、错题本重练，并本地持久化练习历史。

## 二、系统要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11（64 位） |
| 硬件 | 无特殊要求，常规家用电脑即可 |
| 运行库 | 无需安装 Python、浏览器、WebView2 或其他运行时，所有依赖已内置 |
| 网络 | 完全离线运行，无端口监听、无网络请求 |
| 屏幕分辨率 | 最小 1024 × 640（窗口默认 1024 × 720） |

## 三、启动方式

1. 进入发布目录，双击 `dist\CalcStar.exe` 即可运行。
2. 首次启动 Windows SmartScreen 可能弹出"已保护你的电脑"提示：点击 **更多信息 → 仍要运行** 即可（本程序为本地构建，未经代码签名）。
3. 若个别杀毒软件误报，可将 `CalcStar.exe` 所在目录加入白名单。

> 单文件绿色程序，可直接拷贝到其他 Windows 电脑运行，无需安装。

## 四、数据存储位置

- 练习记录数据库（SQLite）：`%APPDATA%\CalcStar\calcstar.db`
- 备份 / 迁移数据：复制上述 `calcstar.db` 文件即可；放到新电脑同一路径下，历史成绩与错题本随之迁移。
- 删除该文件即可清空全部历史与错题数据。

## 五、使用流程

1. **设置练习**：选择运算类别（加法 / 减法 / 加减法 / 乘法 / 除法 / 乘除法 / 四则混合），设置数值范围（10~100 以内或自定义 1~999）、题目数量（20 / 50 / 100 或自定义 1~200）、限时（不限时 / 5 / 10 / 15 / 30 分钟或自定义 1~180 分钟）；可选开启"允许负数"、"包含括号"（仅四则混合有效），并选择每页题数（5 / 10 / 20）。在"算式形式"中还可设置算式目数（两个数 / 三个数 / 随机；四则混合至少三个数）与填空位置（固定末尾 / 位置不定——答案可能在等号后，也可能藏在算式里，如 3 + ( ) - 2 = 5）。
2. **开始练习**：按页作答，翻页保留已填答案；右上角显示计时（限时模式倒计时归零会自动提交）；回车跳转下一题，未作答题目提交前会提示。
3. **提交判分**：提交后展示得分、正确率、用时；全部答对直接显示庆祝画面。可点击"导出成绩单"将本次成绩与逐题明细保存为 PDF（默认文件名含练习时间，可发给家长或打印存档）。
4. **错题订正**：逐题订正错误题目，订正全部答对后标记"已通过"。
5. **返回首页**：可在历史成绩中查看历次练习明细（底部"清空历史"可清空全部练习记录，需连点两次确认，错题本不受影响），在错题本中按类别 / 错误次数筛选错题，或一键"重新练习"错题。

## 六、常见问题

| 现象 | 处理方法 |
| --- | --- |
| 双击无反应 / 被拦截 | 检查 SmartScreen 与杀毒软件拦截记录，加入白名单后重试 |
| 界面空白 | 关闭重新启动；程序为绿色单文件，重启不会丢失数据 |
| 想换一台电脑继续练习 | 拷贝 `exe` 与 `%APPDATA%\CalcStar\calcstar.db`，在新电脑保持相同数据路径 |
| 数据存在哪里 | `%APPDATA%\CalcStar\`（可在文件资源管理器地址栏直接粘贴打开） |

## 七、开发者附录

### 开发态运行

```powershell
.\.venv\Scripts\python.exe -m calcstar        # 或 calcstar 命令
```

测试与覆盖率（阈值 85%）：

```powershell
.\.venv\Scripts\python.exe -m pytest
```

### 重新打包

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

产物为 `dist\CalcStar.exe`（单文件、无控制台窗口、内嵌 web 资源与 QtWebEngine 运行时）。环境变量 `CALCSTAR_DB` 可覆盖默认数据库路径，便于测试隔离。
