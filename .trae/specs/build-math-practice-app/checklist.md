- [x] 存在 `pyproject.toml`（PEP 621，setuptools src 布局），声明 PyQt5/PyQtWebEngine 依赖与 dev 依赖组

## 启动与套壳
- [x] venv 内运行 `calcstar` / `python -m calcstar` 能打开原生窗口并加载本地前端资源，窗口初始尺寸约 1024×720
