# Checklist

## 启动与套壳
- [ ] `python main.py` 能打开原生窗口并加载本地前端资源，窗口初始尺寸约 1024×720
- [ ] 运行期不启动 HTTP 服务、不监听任何端口，无需浏览器参与
- [ ] 关闭窗口后进程完全退出，无残留后台进程
- [ ] 首次运行自动在用户数据目录创建 SQLite 数据库与表结构
- [ ] 缺少 WebView2 运行时时有明确弹窗提示并正常退出，不静默崩溃

## 独立可执行文件
- [ ] `build.ps1` 可一键打包，产出单文件 `dist\CalcStar.exe`
- [ ] 双击 exe 直接打开桌面窗口，无控制台窗口、无浏览器标签页
- [ ] exe 内置前端资源，运行时不请求任何外网资源
- [ ] 将 exe 复制到其他目录/机器后可直接运行并创建本地数据库

## 仓库与工程化
- [ ] 已执行 `git init`，`.gitignore` 正确忽略 `__pycache__`、`.venv`、`build/`、`dist/`、`*.db` 等
- [ ] 存在 `pytest.ini` 与 `tests/conftest.py`（临时数据库 fixture）
- [ ] `pytest --cov=app --cov-fail-under=85` 全部通过且覆盖率达标
- [ ] 测试覆盖各类别约束、参数边界、判分、订正闭环、错题聚合、历史查询、超时提交与桥接错误封装

## 设置页面
- [ ] 运算类别包含 加法/减法/加减法/乘法/除法/乘除法/四则混合运算
- [ ] 数值范围提供 10/20/30/50/100 预设并支持自定义
- [ ] 题量提供 20/50/100 预设并支持自定义（1–200）
- [ ] 限时提供 不限时/5/10/15/30 分钟并支持自定义
- [ ] 四则混合运算可开关"包含括号"，可开关"允许负数结果"
- [ ] 每页题数可选（5/10/20）
- [ ] 非法参数有页内提示且不进入做题页
- [ ] 设置页为左右分区布局，右侧含卡通装饰与醒目的开始按钮

## 出题引擎
- [ ] 加减法题目与结果均落在设定范围内，减数不大于被减数（未允许负数时）
- [ ] 乘除法乘积不超过范围，除法均整除且除数不为 0
- [ ] 四则混合运算遵循先乘除后加减，除法步骤整除，中间结果不越界
- [ ] 同一份练习中题目不重复
- [ ] 生成器单元测试 `pytest tests/test_generator.py` 全部通过

## 做题页面
- [ ] 题目以行列网格展示，题目超出每页数量时出现分页控件
- [ ] 翻页后已填答案保留
- [ ] 限时模式右上角倒计时，归零自动提交
- [ ] 不限时模式右上角正向计时且不自动提交
- [ ] 底部"提交"按钮可提交并进入结果页

## 判分与订正
- [ ] 提交后展示正确数、百分制得分、正确率与用时
- [ ] 未作答题目按错误计分
- [ ] 结果页列出全部错题（题目/你的答案/正确答案）
- [ ] 错题可编辑并"提交订正"，仍有错时继续订正
- [ ] 全部订正正确后才标记"已通过"，并可返回设置页面
- [ ] 订正轮次被记录

## 历史与错题集
- [ ] 历史成绩按时间倒序展示时间、类别、范围、题量、用时、得分、是否通过
- [ ] 可查看单次练习逐题明细
- [ ] 错题集按"表达式+正确答案"聚合，记录错误次数与最近错误时间
- [ ] 错题集支持类别筛选与按错误次数排序
- [ ] 可从错题集发起新的错题练习并完成闭环

## 界面风格（儿童活泼风）
- [ ] 配色符合规范：奶油底 `#FFF9F2`，主色橙 `#FF8A3D`，辅色黄/绿/蓝/紫，正确绿 `#2FBF71`、错误红 `#FF5A5F`
- [ ] 卡片圆角 24px、按钮胶囊形、输入框 16px 圆角，使用柔和彩色投影
- [ ] 使用内联 SVG/CSS 绘制星星、奖杯等卡通装饰，无外链字体或图片
- [ ] 按钮悬停上浮/按下缩放、页面切换与卡片入场有过渡动效，答对打勾弹跳、得分数字滚动
- [ ] 支持 `prefers-reduced-motion` 关闭动效
- [ ] 所有交互元素有清晰 `:focus-visible` 焦点环
- [ ] 960×640 最小窗口下布局不破版，做题页为 3–4 列自适应网格
- [ ] 倒计时、得分、错对状态有明确的颜色与图形强调

## 数据
- [ ] 重启应用后历史成绩与错题集数据仍然存在
